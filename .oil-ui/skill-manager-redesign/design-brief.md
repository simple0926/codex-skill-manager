# Codex Skills Control 改版说明

- 用户与场景：在桌面端管理本机 Codex Skills，需要快速浏览、筛选、判断维护状态，并安全执行更新、卸载与恢复。
- 设计北极星：让维护判断比浏览信息更快，让危险操作比普通操作更克制。
- 首屏主角：高密度、可扫描的 Skills 数据表。
- 主动作：选择一项 Skill，在不离开列表的情况下检查详情并预览更新。
- 方向：沿用已选方案 2，采用表格工作台 + 持久右侧详情面板；浅色中性背景、石墨色顶栏、薄荷绿操作色、低装饰度。
- 关键状态：全部、需关注、可更新、90 天未使用；来源未知不伪装成 0；卸载藏入更多菜单并继续使用预览与确认短语。
- 设备：主视口 1440×1024；窄于 980px 时详情面板转为覆盖式抽屉；表格允许横向滚动但主操作保持可达。
- 控件语法：6–8px 圆角、1px 低对比边框、44px 主要点击区、2px 高对比焦点环；Phosphor regular 图标统一 20px。
- 动效：咔嗒式按压反馈；状态标签切换 180ms；详情面板 280ms 阻尼滑入；首次进入仅对主表与详情做一次轻量出场，并尊重 reduced-motion。
- 验收重点：中文正文不小于 13px；键盘可操作；焦点不被固定栏遮挡；1440/1024/768/375 宽度无不可恢复的遮挡；危险操作可撤销或恢复。
- 主动放弃：大号 KPI 首屏、左侧长筛选栏、红色显眼卸载按钮、装饰图表、暗色默认主题。
