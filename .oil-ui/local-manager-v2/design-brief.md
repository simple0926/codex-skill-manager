# Local Manager V2

- 北极星：让每一行都明确下一步能做什么，并把不可逆操作留到最后。
- 用户：在本机安装了较多 Codex Skills、需要维护与清理的人。
- 主视口：1440×900 桌面；390×844 手机作为检查视口。
- 主角：当前可管理的 Skill 清单。
- 主动作：更新当前 Skill；卸载降级到详情和二次确认。
- 范围：只显示可更新或可恢复卸载的 Skill；系统与插件托管项继续隐藏。
- 视觉方向：深墨绿操作栏、温白数据面、单一荧光绿状态指示；高密度但不拥挤。
- 动效：首屏顺序进入、选中行与详情连续切换、执行按钮即时按压反馈。
- 验收：发现页完全剥离；本地扫描、筛选、详情、预览、更新、卸载、恢复可用。
- 评审：当前环境不允许独立子 Agent，采用主 Agent 自检并明确标注。
